# Public media

These assets describe **DeepSeek Dock 0.1.0-beta.1**. The plugin is currently verified only on macOS / DeepSeek Harness 0.2.1-rc.5.

- `hero.svg` / `hero.en.svg`: deterministic interface illustrations for the Chinese / English README.
- `demo.mp4`: 45-second simulated feature animation, 1920 × 1080, 30 fps, silent. Reproducible sources live in `../../demo/`.
- `poster.png`: complete simulated workspace with the notes drawer at 23.5 seconds.
- `dock-collapsed.png`, `dock-customize.png`, `pinned-chats.png`, `video-preview.png`: simulated frames for the community gallery, each visibly stamped “模拟演示 / SIMULATED DEMO”.

所有会话、项目、文件与视频画面均为自制模拟内容；没有用户的私人截图。动效说明功能，不是实机性能证明。英雄图为界面示意，播放预览里的几何动画是本项目原创示例。

All chats, projects, files, and video content are fictional examples. No private user screenshots are included. The animation explains behavior; it is not a live performance claim. The hero images are interface illustrations, and the geometric video sample is original project artwork.
