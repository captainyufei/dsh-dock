# Public media

These assets describe **DeepSeek Dock 0.1.1**. The plugin is currently verified only on macOS / DeepSeek Harness 0.2.1-rc.5.

- `hero.svg` / `hero.en.svg`: deterministic interface illustrations for the Chinese / English README.
- `preview.gif` / `preview.en.gif`: Chinese / fully English 45-second silent README loops, 1200 × 675, 15 fps, infinite looping. They show the complete story: persistent Dock and Codex-inspired layout, selecting/reordering tools, global pins across two workspaces, draft-to-send chat creation, existing file tabs and video playback/seeking. The first and last composited frames are identical.
- `demo.mp4` / `demo.en.mp4`: Chinese / English 45-second simulated feature animations, 1920 × 1080, 30 fps, with a shared instrumental background track. Reproducible sources live in `../../demo/`.
- `poster.png` / `poster.en.png`: the corresponding language edition's simulated workspace with the notes drawer at 31 seconds.
- `dock-collapsed.png`, `dock-customize.png`, `pinned-chats.png`, `video-preview.png`: simulated frames for the community gallery, each visibly stamped “模拟演示 / SIMULATED DEMO”.

README 中的 GIF 可自动循环播放，点击后打开对应语言的完整 45 秒有音乐演示；原 MP4 和静态海报继续保留。
